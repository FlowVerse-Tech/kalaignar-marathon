## 2. Technical Performance & Optimization Details
- **Format:** Converted all raw source files (JPEG, PNG) to Google WebP format (~80 quality factor), resulting in **85%–92% file size reduction** while preserving sharp edges and color fidelity.
- **Blur Placeholders:** Generated lightweight base64 blur hash strings for every photo, eliminating content layout shift (CLS) and providing seamless progressive loading.
- **Responsive Sizing:** Set explicit `sizes` attributes tailored to standard breakpoints (`375px`, `768px`, `1024px`, `1440px`, and `1920px`).
- **Priority Loading:** Constrained `priority={true}` strictly to the primary Hero background image to maximize Largest Contentful Paint (LCP) performance; all other assets utilize Next.js native lazy-loading.
- **Containment for Logos:** Configured `objectFit="contain"` on all record body seals within `ImpactStats.tsx` so seals remain uncropped across desktop and mobile screens.
